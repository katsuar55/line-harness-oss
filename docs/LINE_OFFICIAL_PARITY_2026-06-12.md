# LINE公式ネイティブ機能 vs Harness 差分表 (2026-06-12)

> **目的**: 「LINE公式 (OA Manager / Messaging API) で出来上がっているものは作らない」という build-vs-use 判断の単一参照点。
> 4並列リサーチ (一次情報: lycbiz マニュアル / developers.line.biz news) に基づく。2026-06 時点。

## 結論サマリ

1. **現在の Harness の build 判断はほぼ全面的に正当** — 購買データ連動・個別化・API 露出は 2026 年現在も LINE 公式の空白地帯。
2. **ネイティブ A/B テストは廃止済み** (2024-10 新規停止 → 2025-03-05 完全終了)。Harness の A/B 管理UI (#115) は重複ではなく市場の空白を埋める実装。
3. **ショップカードは「ポイント機能」の代替にならない** (QR 手動付与のみ・金額連動不可・API ゼロ)。自社ロイヤリティ (rank engine + マイランク LIFF) は build 継続が正解。
4. **クーポンは 2025-08 から Messaging API 完全対応** — LINE 内完結クーポンは自前実装せず native API を use。Shopify 連動の顧客別コード (NLR-) のみ Harness の責務。
5. **二重返信はプラットフォームでは防がれない** — Harness 運用中のネイティブ設定は「チャットON(手動のみ) + Webhook ON、ネイティブ自動応答系 全オフ」が正解 (現 runbook 通り)。

## 🟢 公式に任せる (Harness で作らない / 捨てる)

| 機能 | 根拠 | 備考 |
|---|---|---|
| 汎用クーポン (抽選/友だち紹介) | Coupon API 2025-08-06 提供開始、OA Manager と相互運用 | reply 送信なら通数無料。SDK に薄ラッパー追加は将来オプション |
| LP到達者リターゲティング | 計測タグ×ウェブトラフィックオーディエンス (2026-01-21) | 自前クリック計測の拡張は不要 |
| 開封/クリック リターゲティング | ネイティブオーディエンス (過去60日、min 50人) | 自前インプレッション計測は作らない |
| 汎用の予約一斉配信 (属性絞り込み) | ネイティブで成熟 (編集/テスト配信/配信数上限) | Harness 独自セグメント宛のみ自前 cron |
| 月額課金メンバーシップ | ネイティブ (月額400〜15,400円、決済/解約をLINEが完結) | 有料ファンクラブをやる時は native + メンバーシップAPI |
| LINEコール | ネイティブ無料 | — |
| 有人チャット escalation | Webhook ON + 手動チャット併用可 (2022-11〜排他撤廃) | Harness chats UI と OA Manager チャットの両方が選択肢 |
| 静的FAQボット (代替検討時) | AIチャットボット(β) 2025-11、チャットPro 月3,000円 | Q&A 100件上限・自由生成なし → 現状は Harness AI が優位 |

## 🟡 併用 / ハイブリッド (役割分担)

| 機能 | 分担 |
|---|---|
| セグメント配信 | **計算=Harness** (購買/タグ/ランク) → ①50人以上: userId アップロードオーディエンス経由でネイティブ絞り込み配信も可 ②50人未満: Harness multicast 直送のみ |
| あいさつメッセージ | どちらか一方のみ (二重挨拶)。出し分け不要なら native (無料5吹き出し)、経路/顧客状態別出し分けは Harness follow handler |
| クーポン配布 | LINE内完結 = native Coupon API / Shopify 決済連動・顧客別ユニークコード = Harness (実装済) |
| 通数予算 | API push もネイティブ配信も**同一プール消費** → Harness 側に予算管理を一元化、ネイティブ配信は把握できる範囲に限定 |

## 🔴 Harness 必須 (公式では不可能 = 存在意義)

| 機能 | 公式の壁 |
|---|---|
| 購買データ/タグ連動ステップ・販促配信 (tag-elapsed) | ネイティブの分岐は「みなし属性(推計値)+オーディエンス」のみ。時間も日単位のみ |
| A/Bテスト | **ネイティブ機能は 2025-03-05 完全廃止**。旧機能の 5,000人以上制約も Harness には無い |
| 会員ランク/ロイヤリティ (rank engine/マイランク/ランク割引) | ショップカードは QR 固定ポイントのみ・金額連動不可・付与/照会 API なし |
| AI 自動応答 (Workers AI 3層) | 旧AI応答は 2023-11 廃止。後継 β は有料 (月3,000円)+Q&A 100件+タグ連動なし |
| 顧客別ユニーク割引コード (NLR-) | ネイティブクーポンは共通コードのみ |
| 個人特定アンケート→タグ付け→配信 | ネイティブリサーチは匿名集計専用 (回答20件未満DL不可・個人特定不可) |
| 友だち↔Shopify顧客連携 / 注文連動 | 該当機能なし |
| AI Conductor (NL→設定生成) | 公式は LINE Bot MCP Server (送信系の薄いpreview) のみ |
| 経路別あいさつ出し分け | ネイティブは1種類・全員一律 |

## ⚠️ 調査で判明した要対応事項 (新規リスク)

1. **レートリミット引き下げ傾向**: multicast (2025-04-23) / **rich menu list 2,000→10 req/s (2026-05-26)**。
   → Harness の一斉送信・importer・リッチメニュー操作に 429 リトライ+ペーシングが必須。要コード確認。
2. **Business Manager 連携必須化**: 2026-03 までに日本の全 LINE 公式アカウントで必須。
   → 本番 OA の連携状態確認をカットオーバー runbook (task #8) に追加。
3. **料金改定 2026-10-01**: スタンダードの追加メッセージが「20万通まで3円/超過2.5円」2段階制へ。月5万通以下は影響なし。
4. **LIFF→LINEミニアプリ統合** (2025-02 発表): 既存 LIFF は後方互換で安全。新規フロント画面は未認証ミニアプリ (審査不要) を標準検討。
5. **reply token は引き続き通数無料** → AI 自動応答を reply で返す現行設計はコストゼロで正解 (継続)。

## 運用設定の正解 (本番 OA、カットオーバー時)

```
OA Manager 応答設定: チャット ON (手動のみ) / あいさつメッセージ OFF / 応答メッセージ OFF / AIチャットボット OFF
LINE Developers: Webhook ON
理由: 二重返信はプラットフォームで防がれない (優先順位制御なし・並行発火)。
唯一の禁止組合せ = Webhook/応答/あいさつ全部OFF。
```

## タスクへの影響

- task #6 (アンケートUI): ネイティブリサーチは匿名集計専用 → **個人特定+タグ連動が要件なら build 継続** (既存 forms は稼働済)。単純世論調査だけなら native で足りる → Katsu の用途確認で決める。
- 「ポイント/マイル」 (intent-router が未実装と回答中): ショップカードでは代替不可と確定。やるなら Harness 自前 (launch 後)。
- クーポン API ラッパー (line-sdk): launch 後の追加候補 (use 方針)。
